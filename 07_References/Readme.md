# 📁 07_References

This directory contains the academic citations, framework documentation, and software licenses that support the **Privacy-Preserving Big Data Security Framework** research proposal. 

## 📂 Directory Contents

### 1. Academic Citations (`/citations`)
Contains the exported citation files (BibTeX and RIS formats) for the core peer-reviewed literature and standards foundational to this framework's methodology.
* **`Proposal_References.bib`** - BibTeX export file.
* **`Proposal_References.ris`** - RIS export file for Mendeley/Zotero.

**Core References Included:**
* Al-Zubidat, M. A., & Al-Qur'an, M. S. (2022). Comprehensive survey on security challenges and privacy preservation mechanisms in distributed Big Data processing. *Journal of Big Data Analytics and Security*, 14(2), 105–124.
* Chen, X., Li, J., & Wang, H. (2021). Efficient data-at-rest encryption scheme for distributed file systems with low computational overhead. *IEEE Transactions on Dependable and Secure Computing*, 18(5), 2310–2322.
* Hashim, S. N., & Rahman, A. A. (2023). Privacy-preserving access control mechanisms in cloud-based multi-tenant Big Data architectures. *Cybersecurity and Data Protection Journal*, 9(1), 45–59.
* Kumar, P., & Sharma, V. (2020). Performance impact of cryptographic operations on distributed storage nodes: Benchmark and optimization. *Computers & Security*, 98.
* National Institute of Standards and Technology. (2020). NIST Special Publication 800-188: De-identifying government data sets for Big Data security and privacy.
* Zhang, Y., & Liu, M. (2024). Role-based fine-grained access policy enforcement in multi-node data clusters. *Journal of Network and Computer Applications*, 221.
* Amaithi Rajan, A., & Vetriselvi, V. (2024). Systematic survey: Secure and privacy-preserving big data analytics in cloud. *Journal of Computer Information Systems*, 64(1), 136–156.

### 2. Framework & API Documentation (`/documentation`)
Contains offline copies and direct links to the official documentation for the core technologies driving the experimental testbed.
* **`Apache_Hadoop_HDFS_Sec_Guide.pdf`** - Official documentation detailing native HDFS security configurations.
* **`Apache_Spark_Distributed_Processing.md`** - Reference links and API guidelines for Spark's distributed processing.

### 3. Software Licenses (`/licenses`)
Contains the legal licensing agreements to ensure academic integrity and compliance for the open-source tools utilized in this testbed.
* **`APACHE-2.0-LICENSE.txt`** - License covering the use of Apache Hadoop and Apache Spark.
