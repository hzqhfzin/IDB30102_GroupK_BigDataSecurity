CHAPTER 2: LITERATURE REVIEW 
2.1 Overview of Big Data Security Challenges  
The rapid expansion of enterprise data environments has fundamental transformed modern organizational decision-making processes, yet it has simultaneously exposed critical vulnerabilities in large scale data processing infrastructures. Big Data architectures are inherently characterized by the core dimensions of Volume, Velocity, Variety, Veracity and Value. While these characteristics enable unprecedented real-time analytical capabilities, they introduce complex security paradigms that traditional perimeter-based security measures fail to address adequately. In high volume streaming environments, traditional access control mechanisms and single node inspection firewalls become severe processing bottlenecks, leading organizations to balance performance against rigorous security controls. 
Threat actors actively exploit the decentralized nature of distributed nodes through sophisticated attack vectors, including unauthorized data access, privilege escalation and side channel data leakage. Furthermore, data ingestion pipelines frequently combine structured, semi structured and unstructured data from heterogeneous sources, which complicates the uniform enforcement of encryption and data masking policies. The fundamental conflict in Big Data security revolves around maintaining data utility for analytical algorithms while upholding strict data confidentiality and privacy guarantees. As enterprise architectures transition toward multi tenant cloud ecosystems, risks surrounding data provenance, unauthorized reidentification and regulatory compliance breaches expand exponentially, necessitating structural security integration directly into distributed storage engines and processing frameworks. 
2.2 Security Architectures in Distributed File Systems  
Distributed File Systems, such as the Hadoop Distributed File System, Apache Ozone and cloud native Object Stores like Amazon S3, form the foundational storage infrastructure for modern Big Data analytical clusters. However, their core architecture, which relies on replicating data blocks across geographically or logically distributed physical DataNodes, introduces distinct security challenges. Security architectures in distributed storage environments must ensure robust user authentication, fine grained access authorization, transparent data at rest encryption and wire level transport security without incurring acceptable latencies or computational bottlenecks. 
Modern distributed file systems integrate multi-layered security frameworks to mitigate these risks. Kerberos is widely deployed to provide strong mutual authentication between client applications, NameNodes and DataNodes, preventing impersonation attacks. Authorization is enforced using standard File System Access Control Lists combined with centralized policy engines, such as Apache Ranger or Apache Sentry, to maintain consistent rule enforcement across complex multi tenant clusters. To protect sensitive data at rest, Transparent Data Encryption isolates sensitive storage zones and encrypts individual data blocks using key management servers. However, applying cryptographic operations at scale introduces significant performance overhead, where symmetric cryptographic primitives provide hardware accelerated throughput, whereas asymmetric and advanced homomorphic primitives introduce severe latency constraints.

Early methodologies prioritized identity protection in static relational databases, whereas modern solutions focus on dynamic data streams and distributed machine learning pipelines. 2.4 Research Gap 
A comprehensive synthesis of existing literature reveals several critical research gaps in the domain of Big Data privacy protection. The primary research gap lies in the persistent utility privacy imbalance encountered when processing high dimensional data streams. Conventional Local Differential Privacy frameworks apply uniform noise injection mechanisms across all data attributes regardless of their underlying analytical significance. When scaled to continuous, high velocity streaming datasets, this indiscriminate noise addition severely degrades statistical utility and destroys non linear feature correlations that are essential for accurate real-time machine learning and analytics. 
Furthermore, current privacy implementations suffer from rigid privacy budget allocation models. In real world multi query environments, systems rely on static privacy budgets that accumulate consumption exponentially over continuous queries. Once the privacy budget is fully depleted, systems are forced to either halt analytical query execution entirely, causing service disruptions, or proceed with unbudgeted queries that expose individual records to privacy reconstruction attacks. Existing literature lacks dynamic mechanisms capable of adjusting privacy parameters based on real time threat assessments, query contexts and changing data distributions. 
Lastly, severe architectural scalability bottlenecks remain unaddressed in distributed processing environments. Advanced cryptographic paradigms such as Fully Homomorphic Encryption demand immense computational overhead, resulting in processing latencies that are impractical for production Big Data workloads. On the other hand, classic heuristic anonymization approaches scale with quadratic computational complexity, making them inefficient for massive, unstructured storage engines like distributed object stores. There remains a distinct lack of scalable, lightweight privacy frameworks designed specifically to balance formal mathematical privacy guarantees with high throughput execution in distributed file systems.
