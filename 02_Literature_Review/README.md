# 02 Literature Review and Research Gap Analysis

This repository folder contains the complete academic synthesis, benchmark comparison matrix, and research gap identification for Chapter 2 (Literature Review), focusing on Big Data Security specific to Privacy.

## Structure of Literature Review

### 2.1 Overview of Big Data Security Challenges
Focuses on the 5 Vs of Big Data (Volume, Velocity, Variety, Veracity, Value) and how high-throughput processing creates conflicts between analytical data utility and regulatory compliance (GDPR/PDPA).

### 2.2 Security Architectures in Distributed File Systems
Evaluates authentication (Kerberos), access control (POSIX/Ranger), and Transparent Data Encryption (TDE) across Distributed File Systems (HDFS/S3). Includes Table 2.1 detailing performance overheads across symmetric, asymmetric, and homomorphic encryption.

### 2.3 Summary Matrix of Past Research
Contains Table 2.2, a comprehensive comparison matrix of benchmark studies ranging from classic k-anonymity to modern Local Differential Privacy and Privacy-Preserving Machine Learning frameworks.

### 2.4 Research Gap Identification
Identifies key gaps in current literature, including:
1. Severe data utility degradation in high-dimensional streaming data.
2. Rigid privacy budget allocation in continuous multi-query environments.
3. Computational scalability bottlenecks in distributed processing systems.
